# Agent 持久记忆

## 核心结论

跨会话复用信息需要独立于对话历史的存储、索引、相关性选择和按需读取。记忆应有选择地保留长期有用的信息，而不是把完整聊天记录当成每轮输入。

## 解释与适用条件

教程以单条 Markdown 文件保存记忆，用索引列出记录；新任务先从目录选择相关项，再加载有限数量的正文。当前用户请求优先于旧记忆，召回内容只作背景。回合结束后，候选记忆须经过持久性、完整性及去重检查；仅约束当前任务的信息不应变成跨会话规则。记录增多时可合并重复或过期内容，但需要校验结果并在替换失败时恢复。长期运行还要考虑并发写入和旧事实失效。
