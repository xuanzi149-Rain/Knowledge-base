# Agent MCP 工具接入

## 核心结论

外部工具可通过统一的发现与调用边界加入 Agent 的工具池。运行框架连接服务、获取工具定义、建立处理函数，并在下一轮模型调用前组装当前可用工具，不必为每个服务重写 Agent 循环。

## 解释与适用条件

教程为外部工具使用 `mcp__{server}__{tool}` 名称，规范化名称后检查冲突和长度，再把模型可见定义与实际调用处理函数成对加入工具池。调用时仍需返回对应工具结果；参数错误可以作为工具错误回传，让模型修正。

服务提供的只读或破坏性提示不是授权。宿主应按服务和工具维护权限策略；未配置的外部工具默认请求确认。该章使用进程内模拟服务演示工具发现与调用边界，**未实现真实 MCP 传输**，因此不能把示例直接视为完整的外部服务连接器。
