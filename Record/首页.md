# 个人知识库

记录开发、生活与专门学习中可长期复用的知识。一个主题一篇笔记，同主题持续补充，通过分类索引和相关知识链接查阅。

## 分类导航

- [[分类/Agent 系统设计|Agent 系统设计]]：Agent 运行框架、工具、安全与上下文管理。

## 开始记录

在 Codex 的任意项目对话中发送：

```text
记录学习：请整理当前对话中关于【主题或范围】的知识，按统一知识库规范生成归档预览。
```

也可以显式调用技能：

```text
$recording-second-brain 请整理当前可见对话中的学习内容，生成归档预览。
```

如果当前环境没有加载技能，发送下面这段即可使用同一套文件规则：

```text
请完整阅读 /Users/wangzixuan/Desktop/How to use Agent/Learn/Record/AGENTS.md
和 /Users/wangzixuan/Desktop/How to use Agent/Learn/Record/系统/归档规范.md。
记录学习：请整理当前可见对话中的学习内容，检索该知识库后生成归档预览，暂不写入。
```

未指定范围时，只整理当前可见对话；较早内容不可见时可补充粘贴。“沉淀知识：”“同时归档：”与“记录学习：”含义相同，均生成主题知识预览。

核对预览后，发送 `确认归档 <预览编号>`。如需改动，直接说明修改要求，系统会给出新编号；发送 `取消归档 <预览编号>` 即可取消。

- [[系统/归档规范|归档规范]]：知识提取、分类、合并和确认规则。
- [[系统/通用记录提示词|通用记录提示词]]：复制到其他聊天工具使用。

在 Obsidian 中选择“打开文件夹作为仓库”，选择本 `Record` 目录即可。无需安装插件。全局技能使用此库的绝对路径；移动知识库后，应同步更新技能与上述入口路径。
